# 更新日志

## [0.1.1] - 2026-01-29

### 文档更新
- **API 参考文档**: 新增完整的 API 文档，包含所有工具的参数列表、返回值类型和错误码说明。
- **使用示例**: 新增实用代码示例，涵盖基础用法、依赖安装、图片生成、文件操作和会话模式工作流。
- **持久化指南**: 新增文件持久化设计的详细文档，以及宿主机挂载存储配置说明。
- **使用指南**: 扩展了高级配置选项，包括自定义 Docker 镜像、并发设置和性能优化建议。
- **文档索引**: 为中英文文档分别添加了 README 索引文件，提供导航指南。

### 变更
- **文档结构**: 将所有文档重组为结构化的 EN/ZH 目录，便于维护。

- **文件组织**: 将所有英文文档从 docs/ 根目录移至 docs/en/，形成统一的目录结构。

### 移除
- **FAQ**: 移除 FAQ 文档（内容已整合到使用指南和其他文档中）。
- **表情符号**: 从文档中移除所有表情符号，呈现更简洁、更专业的风格。
