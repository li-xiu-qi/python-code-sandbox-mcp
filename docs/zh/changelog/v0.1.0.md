# 更新日志

## [0.1.0] - 2026-01-29

### 新增特性
- **生产级核心**：基于 Docker 隔离的 Python 安全执行沙箱。
- **一键执行模式**：`run_python_ephemeral` 工具，支持脚本即时运行与文件回传。
- **会话模式支持**：通过 `sandbox_initialize` 和 `run_python` 维持有状态的开发环境。
- **依赖管理**：自动安装 pip 包，支持通过 `PIP_CACHE_PATH` 实现持久化缓存。
- **安全特性**：Base64 编码代码注入、资源限制（CPU/内存）以及容器内非 root 运行。
- **多架构支持**：Dockerfile 与 CI/CD 全面支持 `amd64` 和 `arm64`。
- **完整文档矩阵**：中英双语的使用指南、架构设计、安全准则及故障排除手册。
- **自动化流水线**：集成代码规范检查、单元测试以及 Docker 镜像自动发布。
