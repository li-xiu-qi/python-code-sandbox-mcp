# Changelog v0.2.2

## Bug 修复

### Docker 镜像依赖缺失修复

**问题**: Docker 镜像中 Python 依赖未正确安装，导致启动时报错：
```
ModuleNotFoundError: No module named 'httpx'
```

**根因**: 
- `uv sync` 默认创建虚拟环境 (`.venv`)
- 原 Dockerfile 设置了 `UV_SYSTEM_PYTHON=1` 但未生效
- ENTRYPOINT 使用系统 Python，而非虚拟环境的 Python

**修复方案**:
- 移除 `UV_SYSTEM_PYTHON=1` 环境变量
- 添加 `ENV PATH="/app/.venv/bin:$PATH"` 使用虚拟环境的 Python
- 保留 `ENV PYTHONPATH=/app/src` 用于源码导入

**文件变更**:
- `Dockerfile`: 修复 Python 环境路径配置
- `.github/workflows/ci.yml`: 添加 Docker 镜像测试步骤

**CI 增强**:
新增以下测试步骤：
1. `Build image (local test)` - 构建本地测试镜像
2. `Test image - Python imports` - 验证所有依赖能正确导入
3. `Test image - Server startup` - 验证服务器能正常启动

**本地验证**:
```bash
# 构建镜像
docker build -t python-sandbox:test .

# 测试导入
docker run --rm python-sandbox:test python -c "import httpx, mcp, dotenv; print('OK')"

# 运行服务器
docker run --rm -v /var/run/docker.sock:/var/run/docker.sock python-sandbox:test
```
