# Changelog v0.2.2 - Docker Hub 迁移

## 变更

### 容器镜像仓库迁移

**从**: GitHub Container Registry (GHCR)  
**到**: Docker Hub

**原因**:
- Docker Hub 在国内访问速度更快
- 更简洁的镜像名（无需 `ghcr.io/` 前缀）
- 避免 GHCR 的流量限制（每月 1GB 出站流量）

**文件变更**:
- `.github/workflows/publish.yml`: 修改推送目标为 Docker Hub
- `.github/workflows/ci.yml`: 更新镜像测试配置
- `README.md`, `README_ZH.md`: 更新镜像引用
- `AGENTS.md`: 更新文档中的镜像地址
- `examples/utils.py`: 更新 `get_docker_server_params` 函数
- `examples/README.md`: 更新示例文档
- `docs/en/PERSISTENCE.md`: 更新持久化文档

**新的镜像地址**:
```
# 旧地址
ghcr.io/li-xiu-qi/python-code-sandbox-mcp:latest

# 新地址
aixiaoke/python-code-sandbox-mcp:latest
```

**用户配置更新**:

```json
{
  "mcpServers": {
    "python-sandbox": {
      "command": "docker",
      "args": [
        "run", "-i", "--rm",
        "-v", "/var/run/docker.sock:/var/run/docker.sock",
        "aixiaoke/python-code-sandbox-mcp:latest"
      ]
    }
  }
}
```

## 迁移步骤

1. 设置 GitHub Secrets: `DOCKERHUB_USERNAME=aixiaoke` 和 `DOCKERHUB_TOKEN`
3. 推送新版本标签触发构建
4. （可选）删除 GHCR 上的旧镜像

详细步骤见 `DOCKERHUB_SETUP.md`
