## 技术说明

### 会话模式的重要澄清

之前的文档存在误导，让用户以为会话模式能保持 Python 变量。实际上：

- [x] **能保持**: 已安装的包、创建的文件
- [ ] **不能保持**: Python 变量、内存状态

每次 `run_python` 调用都是新的 Python 进程，需要通过**文件**来共享状态。

### 文件扫描机制说明

临时模式 (`run_python_ephemeral`) 执行完毕后会自动扫描 `/workspace` 目录：
- 图片文件 → `ImageContent`（可直接显示）
- 文本文件 → `TextContent`（包含文件内容）
- 二进制文件 → `TextContent`（仅返回文件大小）

## 迁移指南

使用会话模式时，如果需要共享数据，请使用文件：

```python
# 错误方式
# 调用 1: code = "df = pd.DataFrame({'a': [1,2,3]})"
# 调用 2: code = "print(df.shape)"  # NameError!

# 正确方式
# 调用 1: code = "df = pd.DataFrame({'a': [1,2,3]}); df.to_csv('data.csv')"
# 调用 2: code = "df = pd.read_csv('data.csv'); print(df.shape)"  # 成功！
```
