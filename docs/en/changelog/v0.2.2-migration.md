# Changelog v0.2.2 - Docker Hub Migration

## Changes

### Container Registry Migration

**From**: GitHub Container Registry (GHCR)  
**To**: Docker Hub

**Reasons**:
- Docker Hub has better access speed in China
- Simpler image names (no `ghcr.io/` prefix needed)
- Avoid GHCR traffic limits (1GB outbound per month)

**File Changes**:
- `.github/workflows/publish.yml`: Changed push target to Docker Hub
- `.github/workflows/ci.yml`: Updated image test configuration
- `README.md`, `README_ZH.md`: Updated image references
- `AGENTS.md`: Updated image addresses in documentation
- `examples/utils.py`: Updated `get_docker_server_params` function
- `examples/README.md`: Updated example documentation
- `docs/en/PERSISTENCE.md`: Updated persistence documentation

**New Image Address**:
```
# Old address
aixiaoke/python-code-sandbox-mcp:latest

# New address (replace aixiaoke with actual username)
aixiaoke/python-code-sandbox-mcp:latest
```

**User Configuration Update**:

```json
{
  "mcpServers": {
    "python-sandbox": {
      "command": "docker",
      "args": [
        "run", "-i", "--rm",
        "-v", "/var/run/docker.sock:/var/run/docker.sock",
        "aixiaoke/python-code-sandbox-mcp:latest"
      ]
    }
  }
}
```

## Migration Steps

1. Set GitHub Secrets: `aixiaoke` and `DOCKERHUB_TOKEN`
2. Replace placeholder `aixiaoke` in code with actual username
3. Push new version tag to trigger build
4. (Optional) Delete old images on GHCR

See `DOCKERHUB_SETUP.md` for detailed steps.
