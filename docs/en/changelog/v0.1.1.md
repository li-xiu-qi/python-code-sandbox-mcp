# Changelog

## [0.1.1] - 2026-01-29

### Documentation
- **API Reference**: Added comprehensive API documentation with complete parameter lists, return types, and error codes for all tools.
- **Examples**: Added practical code examples covering basic usage, dependency installation, image generation, file operations, and session-based workflows.
- **Persistence Guide**: Added detailed documentation for file persistence design and host-mounted storage configuration.
- **Usage Guide**: Expanded with advanced configuration options, custom Docker images, concurrency settings, and performance optimization tips.
- **Documentation Index**: Added README files for both English and Chinese documentation with navigation guides.

### Changed
- **Documentation Structure**: Reorganized all documentation into structured EN/ZH directories for better maintainability.
- **Changelog Format**: Moved changelog files from root to versioned format under docs/en/changelog/ and docs/zh/changelog/.
- **File Organization**: Moved all English documentation files from docs/ root to docs/en/ for consistent directory structure.

### Removed
- **FAQ**: Removed FAQ documentation (content integrated into Usage Guide and other docs).
- **Emojis**: Removed all emoji characters from documentation for cleaner, more professional appearance.
