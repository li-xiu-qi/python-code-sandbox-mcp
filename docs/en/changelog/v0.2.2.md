# Changelog v0.2.2

## Bug Fixes

### Docker Image Dependencies Fix

**Issue**: Python dependencies were not correctly installed in the Docker image, causing errors on startup:
```
ModuleNotFoundError: No module named 'httpx'
```

**Root Cause**:
- `uv sync` creates a virtual environment (`.venv`) by default
- Original Dockerfile set `UV_SYSTEM_PYTHON=1` but it didn't take effect
- ENTRYPOINT used system Python instead of the virtual environment's Python

**Fix**:
- Removed `UV_SYSTEM_PYTHON=1` environment variable
- Added `ENV PATH="/app/.venv/bin:$PATH"` to use the virtual environment's Python
- Kept `ENV PYTHONPATH=/app/src` for source code imports

**File Changes**:
- `Dockerfile`: Fixed Python environment path configuration
- `.github/workflows/ci.yml`: Added Docker image test steps

**CI Enhancements**:
Added the following test steps:
1. `Build image (local test)` - Build local test image
2. `Test image - Python imports` - Verify all dependencies can be imported
3. `Test image - Server startup` - Verify server can start normally

**Local Verification**:
```bash
# Build image
docker build -t python-sandbox:test .

# Test imports
docker run --rm python-sandbox:test python -c "import httpx, mcp, dotenv; print('OK')"

# Run server
docker run --rm -v /var/run/docker.sock:/var/run/docker.sock python-sandbox:test
```
