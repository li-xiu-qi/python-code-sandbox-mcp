## Technical Notes

### Important Clarification on Session Mode

Previous documentation was misleading, suggesting that session mode preserves Python variables. In reality:

- [x] **Persisted**: Installed packages, created files
- [ ] **Not Persisted**: Python variables, memory state

Each `run_python` call starts a new Python process; state must be shared through **files**.

### File Scanning Mechanism

Ephemeral mode (`run_python_ephemeral`) automatically scans `/workspace` directory after execution:
- Image files → `ImageContent` (directly displayable)
- Text files → `TextContent` (includes file content)
- Binary files → `TextContent` (returns file size only)

## Migration Guide

When using session mode, use files to share data:

```python
# Incorrect approach
# Call 1: code = "df = pd.DataFrame({'a': [1,2,3]})"
# Call 2: code = "print(df.shape)"  # NameError!

# Correct approach
# Call 1: code = "df = pd.DataFrame({'a': [1,2,3]}); df.to_csv('data.csv')"
# Call 2: code = "df = pd.read_csv('data.csv'); print(df.shape)"  # Success!
```
